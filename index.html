COURSE 01

Delta Table Crash Course

Delta table lokálisan, Bronze/Silver/Gold rétegek, ETL/ELT pipeline, fact/dimension modellezés, batch és streaming feldolgozás — mind Python és deltalake segítségével. A kurzus végére elkészítesz egy lokálisan futó Delta Lake architektúrát egy webshop rendelési adatbázisra.
Mit építesz?
Egy teljes Delta Lake lakehouse architektúrát lokálisan: nyers rendelés-adatokból Bronze/Silver/Gold rétegeket, star schema modellt (fact_orders + dim_customer, dim_product, dim_date), és futó ETL/ELT pipeline-t.
Stack
Python · deltalake · pandas · Parquet · Delta Lake · dbt · PySpark
Kinek való?
Data Engineer pályakezdőknek, analystoknak akik pipeline-t akarnak építeni, és bárkinek aki meg akarja érteni a modern lakehouse architektúrát.

COURSE 02

AI Engineering

LLM alkalmazások fejlesztése RAG-pipeline-nal: prompt engineering, vektoradatbázisok, evaluációs keretrendszerek, monitoring és éles üzemeltetés a prototípustól a productionig.
Mit építesz?
Egy lokálisan futó RAG chatbotot, ami a webshop termékkatalógusára és rendelési adatokra válaszol — vektoradatbázissal, eval pipeline-nal (RAGAS), LangFuse monitoringgal és Streamlit UI-val.
Stack
Python · OpenAI API · LangChain · ChromaDB · Streamlit · RAGAS · LangFuse
Kinek való?
Fejlesztőknek akik LLM alkalmazásokat akarnak építeni, data scientisteknek akik a prototípust production-vé akarják alakítani, és mérnököknek akik RAG rendszert akarnak.

COURSE 03

AIOps & MLOps

ML modellek éles üzemeltetése CI/CD pipeline-nal: MLflow tracking és registry, Docker konténerizáció, Kubernetes deployment, monitoring, drift detection és canary release.
Mit építesz?
Egy teljes ML deployment pipeline-t: a webshop churn prediction modelltől a konténerizált FastAPI szolgáltatásig — MLflow trackinggel, Docker image-dzsel, K8s deploymenttel, Prometheus monitoringgal és canary release-szel.
Stack
Python · MLflow · Docker · Kubernetes · FastAPI · Prometheus · GitHub Actions
Kinek való?
MLOps engineers-öknek, senior data scientisteknek akik production-t céloznak, és DevOps mérnököknek akik ML workload-okat akarnak menedzselni.

COURSE 04

AI Data Engineer

AI-ready adatpipeline-ek építése: feature store, adatminőség-ellenőrzés, streaming ingestion, data catalog és lineage — az adatforrástól a modellezésig.
Mit építesz?
Egy feature store-t és streaming adatpipeline-t a webshop subscription adatokra: Feast feature store Great Expectations adatminőséggel, Kafka streaming ingestion-nel, Airflow orchestrationnel és teljes data lineage-nel.
Stack
Python · Feast · Airflow · dbt · Delta Lake · Great Expectations · Kafka · Spark
Kinek való?
Data engineer-eknek akik AI-ready adatinfrastruktúrát akarnak, ML engineer-eknek akik meg akarják érteni az adatoldalt, és architect-eknek akik end-to-end pipeline-t terveznek.

COURSE 05

Apache Spark

Elosztott adatfeldolgozás Sparkkal: RDD-k, DataFrame API, Spark SQL, Structured Streaming, performance tuning, cluster management és valós ETL feladatok.
Mit építesz?
Egy elosztott ETL rendszert a webshop adatokra: többforrásos join-okat (rendelések + ügyfelek + termékek), aggregációkat, Structured Streaming pipeline-t és MLlib alapú ajánló modellt — mind PySparkkal.
Stack
PySpark · Spark SQL · Structured Streaming · MLlib · Hadoop · Hive · Delta Lake
Kinek való?
Data engineer-eknek akik nagy adatmennyiségekkel dolgoznak, Sparkot használó csapatokba készülőknek, és bárkinek aki elosztott feldolgozást akar elsajátítani.
