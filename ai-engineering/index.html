LLM alkalmazások fejlesztése RAG-pipeline-nal OpenAI Python

Ez a kurzus azt mutatja meg, hogyan építs LLM-re épülő alkalmazásokat a prototípustól az éles üzemeltetésig.

RAG = Retrieval-Augmented Generation
= a modell nem csak a saját tudásából válaszol,
  hanem egy dokumentumtárból is keres releváns információt

Nem modelleket tanítunk — alkalmazásokat építünk meglévő LLM-ek (OpenAI GPT, Anthropic Claude) köré.

Miről szól?

LLM API → Prompt engineering → Embeddingek → Vektoradatbázis → RAG pipeline → Evaluáció → Monitoring → Éles üzem

Embeddingek és vektorok

Az embedding szöveget vektorrá alakít. Hasonló szövegek → hasonló vektorok.

"kutya" → [0.12, -0.34, 0.56, ...] # 1536 dimenzió
"cica"  → [0.11, -0.33, 0.55, ...] # nagyon hasonló!
"autó"  → [0.45, 0.89, -0.12, ...]  # teljesen más
[s6]
import numpy as np
texts=["A kutyák hűségesek","A macskák függetlenek","A Python nyelv"]
resp=client.embeddings.create(input=texts,model="text-embedding-3-small")
vecs=[d.embedding for d in resp.data]
print(f"Dim: {len(vecs[0])}")
def cs(a,b): return np.dot(a,b)/(np.linalg.norm(a)*np.linalg.norm(b))
print(f"kutya↔macska: {cs(vecs[0],vecs[1]):.4f}")
print(f"kutya↔python: {cs(vecs[0],vecs[2]):.4f}")
Output:
Dim: 1536
kutya↔macska: 0.7823
kutya↔python: 0.3214

def chunk(text,sz=200,ov=50):
    c=[];s=0
    while s<len(text): c.append(text[s:s+sz]);s+=sz-ov
    return c
chunks=chunk("Delta Lake..."*10)
print(f"Chunks: {len(chunks)}, Size: {len(chunks[0])}")
Output:
Chunks: 8, Size: 200

LangChain alapok LangChain

A LangChain a legnépszerűbb LLM framework: chains, prompts, output parsers, LCEL.

[s12]
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

llm=ChatOpenAI(model="gpt-4o")
prompt=ChatPromptTemplate.from_messages([
    ("system","Válaszolj röviden."),("user","{q}"),
])
chain=prompt|llm|StrOutputParser()
resp=chain.invoke({"q":"Mi a vektoradatbázis?"})
print(resp[:200])
Output:
Egy vektoradatbázis nagy dimenziós vektorok tárolására optimalizált adatbázis. AI alkalmazásokban használják tartalom-alapú keresésre.
